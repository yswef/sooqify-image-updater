# Sooqify Image Updater

أداة سطح مكتب (Windows) لفريق التصميم - تستبدل صور المنتجات المعدَّلة على
Sooqify تلقائياً، بحث آمن بالتحقق من هوية المنتج، مزامنة كاملة مع نظام
AlphaCode المركزي، وتقارير أداء لكل مصمم.

تطوير: يوسف الحمزي
