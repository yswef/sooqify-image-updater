Sooqify Image Updater — دليل المطوّر

دليل مبني على قراءة هذا الـ checkout كما هو، وليس على افتراض أن الموقع أو إضافة AlphaCode مطابقة لتعليقات الكود.

مراجعة المصدر: 2026-09-30 · الملفات المرجعية: app/ وtests/ · واجهة الدليل مستقلة ولا تحتاج مكتبات خارجية

تنبيه مهم قبل أي تشغيل حي: في الواجهة، خانة «وضع المراجعة» غير محددة افتراضياً، وكل المنتجات تُحدَّد تلقائياً بعد الفحص؛ والرفع الآلي ينقل المجلدات افتراضياً. لذلك زر «ابدأ» قد يعني رفعاً حقيقياً وأرشفة، وليس معاينة. لا تعتمد على كلمة Dry Run وحدها قبل فهم السلوك أدناه.

ما الذي تفعله الأداة بالضبط؟

تطبيق سطح مكتب Python بواجهة HTML/JavaScript عبر PyWebView. يفحص مجلداً محلياً، يربط كل مجلد صور بمنتج في لوحة سوقيفاي باستخدام Playwright، يعبّئ حقول الصور، ثم إمّا يترك النموذج للمراجعة اليدوية أو يضغط «اعتماد» آلياً ويسجّل النتيجة محلياً وبـAlphaCode إذا كانت المزامنة متاحة.

تدفق المنتج من الضغط إلى النتيجة

  1. بدء التطبيق: main() يهيئ السجل، ينشئ نافذة PyWebView بواجهة app/ui/index.html، ويكشف Api إلى JavaScript.
  2. تحميل الإعداد: مستمع pywebviewready في app.js يستدعي get_config(). إذا اكتمل الإعداد، يفتح الشاشة الرئيسية ويطلب فحصاً.
  3. الفحص: scan_products() ينشئ خيطاً خلفياً، وscanner.scan_root_folder() يمشي تحت المجلد الجذر. كل مجلد يحتوي صوراً مباشرة قد يُعتبر منتجاً.
  4. تحديد المنتجات: عند وصول scan_finished، الواجهة تضع كل المسارات في state.selected افتراضياً. يستطيع المستخدم إلغاء الاختيار يدوياً.
  5. بدء الدفعة: الواجهة ترسل المسارات وقيمة مربع المراجعة إلى start_run(). _run_pipeline() يعيد فحص كل مسار، ويرفض المسار خارج الجذر، ثم يطبّق BatchLimit.
  6. جلسة المتجر: يفتح Playwright بروفايل التطبيق الدائم، ثم verify_store_session() يفتح قائمة المنتجات ويتأكد من عنوان/حقل البحث.
  7. البحث والتحرير: process_product_folder() يبحث أولاً بـstyle_code، وإلا بالاسم الإنجليزي/العربي ثم اسم المجلد. يفتح رابط العرض ثم رابط التعديل، ويرسل product_id إلى فحص Tags إن كان متاحاً.
  8. اختيار الملفات: الصورة الأولى حسب ترتيب sort_images() تُعامل كرئيسية والبقية للمعرض. وجود صور معرض قديمة يوقف العملية؛ الكود الحالي لا يحذفها آلياً.
  9. المراجعة أو الاعتماد: وضع المراجعة يعبّئ حقول المتصفح ولا يضغط «اعتماد». الوضع الآلي يضغط الزر وينتظر الانتقال إلى /admin/item/list.
  10. السجل والنقل: في التشغيل الآلي فقط، تُسجّل النتيجة محلياً؛ وحدة done تُدفع فوراً إن أمكن. ثم قد يُنقل مجلد المنتج إلى شجرة _uploaded أو _failed.
  11. المصالحة: في نهاية التشغيل الآلي، قد يسحب التطبيق كل وحدات العمل ويدفع الناقص إذا مرّت 6 ساعات أو لم توجد مصالحة سابقة.
المراجعة ليست محاكاة بلا آثار مؤكدة: الكود يستدعي set_input_files() فعلياً على الحقول. لا يضغط زر النموذج النهائي، لكن لا نعرف من المستودع وحده إن إضافة الصور ترفع الملفات إلى الخادم فور اختيارها عبر AJAX. تحقّق من الإضافة قبل اعتبار وضع المراجعة آمناً تماماً.

(() => {
    const count = (selector) => {
        try { return document.querySelectorAll(selector).length; }
        catch (_) { return null; }
    };
    const pathOnly = (value) => {
        try { return new URL(value || location.href, location.href).pathname; }
        catch (_) { return ""; }
    };
    const safeField = (el) => ({
        tag: el.tagName.toLowerCase(),
        type: el.getAttribute("type") || "",
        id: el.id || "",
        name: el.getAttribute("name") || "",
        className: typeof el.className === "string" ? el.className : "",
        accept: el.getAttribute("accept") || "",
        multiple: !!el.multiple
        // متعمد: لا نقرأ el.value أو ملفات الحقل أو innerHTML.
    });
    const selectorMap = {
        search: "#datatableSearch",
        tableRows: "table tbody tr",
        mainImage: "#customFileEg1",
        galleryInputs: "input.spartan_image_input",
        spartanRemove: "a.spartan_remove_row",
        removeImageLinks: 'a.spartan_remove_row[href*=\"remove-image\"]',
        viewLinks: 'a[href*=\"/item/view/\"]',
        editLinks: 'a.btn.btn--primary[href*=\"/item/edit/\"]',
        tagCandidates: 'input[name=\"tags\"], input#tags, input[name=\"tags[]\"], select[name=\"tags[]\"], input.tagsinput, .bootstrap-tagsinput input, #tags-select'
    };
    const forms = Array.from(document.forms).map((form) => ({
        method: (form.method || "get").toUpperCase(),
        actionPath: pathOnly(form.getAttribute("action") || location.href),
        fields: Array.from(form.querySelectorAll("input,select,textarea")).map(safeField)
    }));
    const tables = Array.from(document.querySelectorAll("table")).map((table) => ({
        id: table.id || "",
        className: table.className || "",
        headers: Array.from(table.querySelectorAll("thead th")).map((th) => (th.innerText || "").trim()),
        bodyRows: table.querySelectorAll("tbody tr").length
        // لا يقرأ نص صفوف المنتجات.
    }));
    const links = [
        ...Array.from(document.querySelectorAll(selectorMap.viewLinks)).slice(0, 3),
        ...Array.from(document.querySelectorAll(selectorMap.editLinks)).slice(0, 3),
        ...Array.from(document.querySelectorAll(selectorMap.removeImageLinks)).slice(0, 3)
    ].map((anchor) => ({
        className: anchor.className || "",
        path: pathOnly(anchor.getAttribute("href"))
        // query/hash مستبعدان.
    }));
    const summary = {
        page: { origin: location.origin, path: location.pathname, title: document.title, readyState: document.readyState },
        selectors: Object.fromEntries(Object.entries(selectorMap).map(([key, selector]) => [key, count(selector)])),
        forms,
        tables,
        sampleLinkPaths: links,
        dataTablesPresent: !!(window.jQuery && window.jQuery.fn && window.jQuery.fn.dataTable),
        removeLinkPaths: Array.from(document.querySelectorAll(selectorMap.removeImageLinks)).slice(0, 5)
            .map((a) => pathOnly(a.getAttribute("href")))
    };
    console.log("Sooqify DOM probe (read-only; values omitted):", summary);

  6. أضف اختباراً: اختبر النجاح، المدخل غير الصحيح، الوقت المستقطع، غياب selector، والآثار الجانبية. استخدم FakePage/mock requests وisolated_config_dir؛ لا تتصل بمتجر أو خادم حقيقي في اختبار الوحدة.
